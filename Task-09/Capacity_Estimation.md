# Capacity Estimation

## Aim
To estimate the number of containers or virtual machines required to handle 150,000 student logins within two hours.

## Given Information
- Total students = 150,000
- Available time = 2 hours
- Time in seconds = 2 × 60 × 60 = 7,200 seconds

## Calculation

Login rate:

150,000 / 7,200 = 20.83 student logins per second.

Let:
- R = measured requests per second handled by one container.
- Q = average HTTP requests generated by one student login.
- U = target utilisation as a decimal (for example, 0.70 for 70%).

Required instances:

N = Ceiling[(150,000 × Q) / (7,200 × R × U)]

## Result
The required number of containers or virtual machines must be calculated using the actual requests-per-second measurement from Task 8. The final instance count should be rounded up to the next whole number.
