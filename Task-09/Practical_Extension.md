# Practical Extension

## Aim
To add a second service to the existing result portal setup and run both services using Docker Compose.

## Services Used
- Result Portal – the existing university result portal.
- Learning Management System (LMS) – a second service representing the university learning platform.

## Procedure
1. Create a Docker Compose configuration file.
2. Add the result portal service.
3. Add the LMS service.
4. Configure separate ports for both services.
5. Set CPU and memory limits for each service.
6. Start both services using Docker Compose.
7. Check whether both services are running.

## Result
The result portal and learning management system are configured as separate services using Docker Compose.
